## Status tiers

- `delivered` - the task directory satisfies every readiness condition below.
- `under_work` - otherwise.

## Readiness conditions (v2.3)

A task directory is `delivered` when ALL of the following hold:

1. `docs/task.md` exists in the task directory.
2. `evaluation/main.py` exists in the task directory.
3. The task directory contains at least 3 files in total.

There are no additional requirements in v2.3.
